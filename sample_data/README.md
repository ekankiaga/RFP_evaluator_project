# Uploadable demo data guide

All suppliers and claims in this folder are fictional. The PDFs and JSON criteria templates are designed to be uploaded through the normal app workflow and evaluated by Offline demo mode or a tested live provider. They are not pre-scored presentation results.

## Run an evaluation from the sample inputs

1. Start RFP Compass and open **Setup & criteria**.
2. Choose **IT / Software & SaaS** or **Healthcare & Life Sciences**.
3. Under **Use an existing scoring template**, upload the matching JSON file from `templates/`. Review it and click **Apply these criteria**. Generic rows with the same names are merged once.
4. Open **Supplier proposals** and upload all four PDFs from the matching domain folder below. Do not mix domains in a run.
5. Open **Evaluate proposals**. Keep Offline demo mode on for a no-key walkthrough, or use a successfully tested provider for model-based results.
6. Review the Leaderboard and Scorecard. Evidence is organized under criterion-matching headings with explicit strengths, limitations, prices, and gates.

## IT / Software & SaaS

- Template: `templates/it_software_saas.json`
- Proposals: `pdfs/it_software_saas/`
- Expected distinction: Apex has the most complete assurance and service commitments at a premium price. Orbit has current ISO assurance and a balanced offer with weaker recovery targets. BrightPath has a competitive price and delivery plan but its independent audit is in progress. NexaWorks is lowest priced but has material gaps in current assurance, hosting disclosure, and transition support.
- Mandatory gate: a current ISO 27001 certificate or SOC 2 Type II report must be explicitly documented.

## Healthcare & Life Sciences

- Template: `templates/healthcare_life_sciences.json`
- Proposals: `pdfs/healthcare_life_sciences/`
- Expected distinction: Apex has the most complete BAA, validation, interoperability, and support evidence at the highest price. Orbit has a BAA and current ISO assurance with a narrower FHIR package. BrightPath has a BAA and practical validation plan, but no current SOC 2 report. NexaWorks has the lowest-cost proposal but lacks a BAA and has major validation and governance gaps.
- Mandatory gate: the proposal must explicitly offer or include a Business Associate Agreement. Do not infer HIPAA or GxP compliance from general security claims.

## Template files

`templates/` contains JSON criteria lists matching the domain packs. The IT/SaaS and healthcare templates have one generic and one domain-specific row for each criterion. The combined weights total 100%; matching generic rows in an uploaded template update the built-in row once. Upload the matching template for the clearest comparison. Other domain templates are starting examples; adapt them to your real RFP.

## Offline demo behavior

Offline demo mode uses a lightweight deterministic keyword evaluator so the app can run without a provider key. For richer model-based judgments, test and assign a live provider in **Provider connections**. The shared prompt asks providers to use the same score anchors, quote only proposal evidence, and evaluate mandatory gates literally. Different providers can still score differently; human review is required. `sample_data/sample_run.json` is generated by MockLLM and is a technical example, not a curated answer key.

## Parser fixtures

`pdfs/validation_fixtures/` contains a corrupted PDF, a valid PDF with no text, and an image-only PDF. Use them only to demonstrate document handling warnings. OCR is not included.
